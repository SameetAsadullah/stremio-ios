# Security

## Report a problem

Do not open a public issue for a security problem. Use
[GitHub private vulnerability reporting](https://github.com/SameetAsadullah/stremio-ios/security/advisories/new)
or contact the repository owner on GitHub.

Include the steps to reproduce the problem and the iOS and app versions.

## Scope

In scope:

- The iOS app code in this repository
- The loopback proxy and the way the app starts the streaming server

Out of scope:

- Stremio's web app and streaming server. Report those to Stremio.
- MobileVLCKit and nodejs-mobile. Report those to their projects.
